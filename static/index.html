API Endpoints & Tool Calling

Connect vLLM, SGLang, or any agent framework to Ghana Search tools:

1. OpenAI-Compatible Tools Schema
GET https://search.ghanaopenai.org/api/tools
2. National Knowledge Retrieval
curl -X POST https://search.ghanaopenai.org/api/search \ -H "Content-Type: application/json" \ -d '{"text": "who is the current president of ghana", "top_k": 10}'
3. Business Directory & Supplier Locator
curl -X POST https://search.ghanaopenai.org/api/business/search \ -H "Content-Type: application/json" \ -d '{"query": "tractor parts Accra", "top_k": 10}'
